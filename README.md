# E-commerce-sales-project

# Project Overview
This project analyzes e-commerce sales data using Power BI to monitor business performance through interactive dashboards and KPIs.

# Business Problem
The company wants to analyze its sales performance to answer key business questions:

• Which products generate the highest sales?
• Which categories are the most profitable?
• Which regions perform best?
• Which customers contribute the highest revenue?
• How have sales changed over time?

# Objectives
• Analyze sales performance
• Track profit trends
• Compare category performance
• Identify top-selling products
• Analyze regional sales
